# ML-classification-models-
This dataset contains medical diagnostic measurements used to predict the likelihood of diabetes in patient.Each row represents an individual patient’s health profile, with the target variable indicating whether the patient has diabetes.
file name:-Diabetes_prediction.csv
Rows: Each row = one patient record
Columns:
Pregnancies -Number of times the patient has been pregnant
Glucose – Plasma glucose concentration
BloodPressure – Diastolic blood pressure
SkinThickness – Triceps skinfold thickness
Insulin – Serum insulin level
BMI – Body Mass Index 
DiabetesPedigreeFunction – Genetic predisposition score
Age – Patient’s age in years
Diagnosis – Target variable (0 = No diabetes, 1 = Diabetes)

Classification Models: Train algorithms like Decision Tree,SVC, KNN, Random Forest, Logistic Regression
